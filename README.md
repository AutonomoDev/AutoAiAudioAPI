# Auto AI Audio API

[![Maintainability]()]()
[![Test Coverage]()]()

Auto AI Audio API is a project by Autonomo by Autonomous Programming, LLC, 
meant to ease the creation of playable audio from text of any size, from
tiny snippets to complete audiobooks.

https://audio.autonomo.dev/

It includes everything you need for audio output

* Minimum PHP version of v8.1.
* Supports ChatGPT, Anthropic, and DeepSeek AI endpoints.
* Requires a Google Cloud account with the Text To Speech API enabled.
* Requires a services-account.json from Google Cloud.

## Installation

Via Composer

```bash
composer require autonomo/auto-audio-api
```
